# Power BI Dashboards

Power BI work from the Future Connect data analytics course (2026).

| Report | Data | Focus |
|---|---|---|
| [Superstore sales](superstore-sales) | `SampleSuperstore.csv` | Sales and profit by region, category and segment |
| [Supply chain](supply-chain) | `supply_chain_data.csv` | Product revenue, stock levels, lead times and shipping costs |
| [Cookies revenue](cookies-revenue) | Built across Units 1 to 3 | Data modelling, DAX measures and visuals, developed step by step |

## Opening
Open the `.pbix` files in Power BI Desktop (free, Windows).

Power Query transformation, data modelling and relationships, DAX measures, interactive visuals and slicers
